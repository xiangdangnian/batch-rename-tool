# 批量重命名工具

免安装、绿色的小工具：双击就能用。基于 Windows 自带的 PowerShell + WinForms，
不需要安装任何东西，不联网、不写注册表、不产生垃圾文件。

![界面预览](界面预览.png)

## 直接下载

不想用 Git 的话，直接下载打包好的免安装压缩包：
**[批量重命名工具-v2.0.zip](批量重命名工具-v2.0.zip)** —— 解压后双击 `启动.bat` 就能用。

## 特点

- **五种规则**：查找替换（支持正则）、添加 / 删除前后缀、批量编号、大小写转换、修改扩展名
- **实时预览**：调整规则的同时就能看到新文件名，没确认之前绝不动你的文件
- **冲突自动拦截**：重名、非法字符会自动标红并禁止执行；改错了可以一键撤销
- **连锁改名不怕覆盖**：A→B、B→C 这种环形改名会自动用临时名绕开
- **支持高分屏**：150% 缩放下文字依然清晰

## 快速开始

1. 双击 `启动.bat` 打开工具（想完全不闪黑框，就双击 `启动(无黑框).vbs`）
2. 点【添加文件】/【添加文件夹】，或直接把文件拖进列表
3. 选好规则、填好参数，确认预览无误后点【开始重命名】

完整说明见 **[使用说明.md](使用说明.md)**。

## 环境要求

Windows 10 / 11 自带 PowerShell 5.1 即可，无需安装任何依赖。
